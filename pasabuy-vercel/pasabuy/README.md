# Pasabuy on Vercel
1. Push this folder to GitHub.
2. Import the repo in Vercel (Framework Preset: Other).
3. In the Vercel project: Storage > Create > Upstash Redis (free), connect it to the project.
4. Settings > Environment Variables: add ADMIN_PASSWORD (your admin password).
5. Redeploy. Log in with ID: admin and your ADMIN_PASSWORD.
